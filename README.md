# SQL-QUERIES-ON-PIZZA-SALES-


Pizza Sales Analysis (SQL Project)
 Project Overview

This project performs a detailed analysis of pizza sales using SQL queries.
The goal is to uncover trends, identify top-selling pizzas, and provide actionable business insights from the pizza sales database.


 Database Structure

The project uses a relational SQL database with the following tables:

Table Name	Pizza_Project
orders	Contains order information such as order_id, order_date, 
order_details	Includes pizza_id, quantity, unit_price,total_price
pizzas	Pizza details: name, category, size, and base price

 Key SQL Queries

Calculate total revenue and total orders

Identify top 5 best-selling pizzas

Identify bottom 5 least-selling pizzas

Revenue by pizza category and size

Monthly and daily sales trends

Peak order hours and busiest days
